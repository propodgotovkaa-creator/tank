# Читай слоги и стреляй по танкам

Этап: согласование графики. Код игры пока не разрабатывается.

## Фон — вариант 2

Более игровой стиль 3D-аркады: яркая зелень, мягкое освещение, три горизонтальные дорожки. Статус: ожидает согласования.

![Фон — вариант 2](assets/concepts/background-game-v2.png)

Танки: реалистичная военная техника исключительно зелёных армейских оттенков, 3–5 моделей в едином стиле. При попадании небольшая искра, остановка и исчезновение; без взрывов и разрушений.
