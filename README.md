# Читай слоги и стреляй по танкам

Браузерная игра для спокойной тренировки чтения. Выберите согласные и гласные (до 15 букв суммарно), тип слогов и нажмите «На поле». Прочитайте слог и нажмите на танк или табличку. На компьютере прицел следует за мышью; на сенсорном экране достаточно одного касания.

## Возможности

- Четыре зелёные объёмные модели танков; вращение гусениц, повороты, лёгкое покачивание и тени.
- Не более трёх танков на разных маршрутах. Непоражённые танки разворачиваются у края поля.
- Открытые, закрытые и смешанные слоги без повторов в одном раунде.
- Исключаются ЖЫ, ШЫ, ЧЫ, ЩЫ, ЖЯ, ШЯ, ЧЯ, ЩЯ, ЖЮ, ШЮ, ЧЮ, ЩЮ в открытых слогах. Обратные сочетания проверяются независимо.
- При попадании: небольшая искра, торможение, показ слога около секунды, плавное исчезновение.
- Негромкие синтезированные звуки, выключатель звука, повтор раунда и возврат в меню с сохранением выбора.
- Поле 16:9. На вертикальном экране меню перестраивается, поле сохраняет пропорции, размер букв на табличках не опускается ниже 22 px.
- Все ресурсы включены в репозиторий; внешние CDN, аналитика и аккаунты для игры не нужны.

## GitHub Pages

В настройках репозитория откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку **main**, папку **/(root)** и сохраните.

После публикации адрес игры: https://propodgotovkaa-creator.github.io/tank/

Для Genially используйте блок веб-встраивания или iframe:

```html
<iframe
  src="https://propodgotovkaa-creator.github.io/tank/"
  title="Читай слоги и стреляй по танкам"
  width="1920" height="1080"
  style="width:100%;aspect-ratio:16/9;height:auto;border:0"
  allow="autoplay; fullscreen" allowfullscreen>
</iframe>
```

Звук запускается после первого действия пользователя. Если платформа ограничивает звук во вложенных страницах, разрешите его для iframe.

## Локальная проверка

Откройте папку через любой статический HTTP-сервер, например `python3 -m http.server 8000`, затем перейдите на `http://localhost:8000`. Открытие через `file://` не подходит для ES-модулей.

Проверка логики: `node --test tests/logic.test.js` (Node.js 18+).

Проверены: точные наборы слогов, запреты, отсутствие повторов и двойного зачёта, ограничение трёх активных танков, удержание непрочитанного слога, конечность раунда. В браузере проверены выбор и лимит букв, попадание по корпусу и табличке, промах, завершение, сохранение выбора при возврате, а также размеры 1280×720, 1024×768, 844×390, 390×844. Проверка на физических сенсорных устройствах остаётся отдельным этапом.
